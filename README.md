# ⚔️ Iron Ascension (철의 첨탑)

[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-brightgreen?style=for-the-badge&logo=github)](https://jeiel85.github.io/iron-ascension/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](LICENSE)
[![Zero Dependencies](https://img.shields.io/badge/Dependencies-Zero-blue?style=for-the-badge)](index.html)

**Iron Ascension**은 *슬레이 더 스파이어(Slay the Spire)*에서 영감을 받아 제작된 **단일 HTML 파일 기반의 정통 덱빌딩 로그라이크(Roguelike Deckbuilder)** 게임입니다.

외부 이미지, 폰트, 사운드 파일, 빌드 도구(`npm`, `webpack` 등) 일체 없이, 브라우저에서 `index.html` 단 하나를 더블 클릭하는 것만으로 **최소 1시간 이상의 깊이 있는 전략적 플레이**를 제공합니다.

## 📖 세계관 및 배경 스토리
> *"탑의 심연이 울부짖고, 침묵의 기사가 칼날을 벼린다."*
> 
> 저주받은 고대 마수들이 도사리는 15층 높이의 **철의 첨탑**.
> 플레이어는 고독한 '철의 기사'가 되어 탑의 하단에서 시작해 매 층마다 갈림길을 선택하며 전진해야 합니다.
> 전투에서 획득한 카드와 유물로 자신만의 덱 시너지를 구축하고, 정상에 군림하는 **'공허의 군주(The Void Sovereign)'**를 처치하여 첨탑의 저주를 풀어내십시오.

## 🌟 핵심 시스템 및 특징

### 1. 🗺️ 15개 층 절차적 분기 맵 (Procedural Branching Map)
- 1층부터 15층 정상 보스룸까지 이어지는 방향성 비순환 그래프(DAG) 기반 절차적 맵 생성.
- **노드 종류**:
  - ⚔️ **일반 전투 (Battle)**: 기본 몬스터와의 조우 및 골드, 카드 보상 획득.
  - 👹 **엘리트 (Elite)**: 강력한 정예 몬스터. 높은 골드 및 확정 고대 유물 드롭 (검은 별 보유 시 2개).
  - ⛺ **휴식처 (Rest Site)**: 모닥불에서 체력 회복(기본 30%, 승천 3 이상 20%) 또는 덱의 카드 1장 영구 제련(+).
  - 💰 **상점 (Shop)**: 카드 구매, 유물 구매, 덱 정화(불필요한 카드 영구 제거 서비스).
  - ❓ **미지의 조우 (Event)**: 피의 제단, 고대의 대장간, 살아 숨쉬는 벽 등 다크 판타지 선택지 이벤트.
  - 💀 **보스룸 (Summit Boss)**: 15층 정상에 위치한 다단계 페이즈 보스 '공허의 군주'.

### 2. ⚔️ 턴제 전투 & 인텐트(Intent) 시스템
- **에너지 메커니즘**: 턴당 기본 3 에너지 제공. 매 턴 5장의 카드를 뽑고, 턴 종료 시 남은 패를 버림 (덱 소진 시 버린 카드 셔플).
- **인텐트(Intent) 실시간 예고**: 적 머리 위에 다음 턴 공격력, 방어막, 디버프 예고 아이콘 및 수치 표시. 플레이어의 취약/약화 상태를 실시간 반영하여 정확한 데미지 계산.
- **심도 있는 상태이상 시스템**:
  - **힘 (Strength)**: 공격 카드의 피해량 증가 (대검의 경우 3~5배 증폭).
  - **민첩 (Dexterity)**: 방어 카드의 획득 방어도 증가.
  - **취약 (Vulnerable)**: 받는 공격 피해량 50% 증가.
  - **약화 (Weak)**: 주는 공격 피해량 25% 감소.
  - **독 (Poison)**: 턴 종료 시 독 수치만큼 방어도를 무시하고 체력 직접 피해를 입힌 뒤 1씩 감소. 촉매 카드로 2~3배 폭증 가능.
  - **바리케이드 (Barricade)**: 턴이 시작되어도 방어도가 초기화되지 않고 계속 누적.

### 3. 🎴 36종의 고유 카드 & 3가지 핵심 아키타입
모든 카드는 휴식처나 이벤트에서 **강화형(+)**으로 영구 업그레이드가 가능합니다 (수치 대폭 상승 및 코스트 감소).

| 아키타입 | 핵심 메커니즘 | 대표 카드 |
| :--- | :--- | :--- |
| **🛡️ 철벽 & 몸통 박치기 덱** | 방어도를 수백 단위로 누적하여 방패로 적을 압살 | `바리케이드`, `참호(방어도 2배)`, `몸통 박치기(방어도만큼 피해)`, `철옹성(방어도 30~40)`, `흘려보내기` |
| **🧪 맹독 & 촉매 연쇄 덱** | 방어적인 플레이를 유지하며 보스를 독으로 질식사 | `독 묻은 칼날`, `맹독 투척`, `독무 분사`, `촉매(독 2~3배)`, `유독 가스(매턴 독 부여)` |
| **💥 힘 누적 & 연속 타격 덱** | 한계 없는 공격력 펌핑으로 폭발적인 누적 딜링 | `발화`, `악마화`, `한계 돌파(힘 2배)`, `대검(힘 계수 3~5배)`, `연속 타격`, `사신(광역 흡혈)` |

### 4. 🏺 14종의 패시브 고대 유물 (Relics)
- 🩸 **불타는 혈액 (Burning Blood)**: 전투 승리 시 체력 6 회복 (스타터 유물).
- ⚡ **금강저 (Vajra)**: 전투 시작 시 영구 힘 +1 획득.
- 🪨 **매끄러운 돌 (Smooth Stone)**: 전투 시작 시 영구 민첩 +1 획득.
- 닻 **닻 (Anchor)**: 전투 시작 시 10 방어도 획득.
- 🏮 **손전등 (Lantern)**: 전투 첫 턴에 에너지를 1 추가 획득.
- 🛡️ **오리하르콘 (Orichalcum)**: 턴 종료 시 방어도가 0이면 자동으로 6 방어도 생성.
- 🍖 **뼈에 붙은 고기 (Meat on the Bone)**: 전투 종료 시 체력이 50% 이하면 체력 12 추가 회복.
- 🗡️ **쿠나이 (Kunai)**: 한 턴에 공격 카드를 3장 쓸 때마다 민첩 +1 영구 획득.
- ⭐ **수리검 (Shuriken)**: 한 턴에 공격 카드를 3장 쓸 때마다 힘 +1 영구 획득.
- 🌸 **행복한 꽃 (Happy Flower)**: 매 3턴마다 추가 에너지 1 획득.
- 🧩 **백년 퍼즐 (Centennial Puzzle)**: 전투 중 처음 피해를 입었을 때 카드 3장 추가 드로우.
- 🧇 **리씨의 와플 (Lee's Waffle)**: 획득 시 최대 HP +10 증가 및 체력 완전 회복.
- 👑 **황금 우상 (Golden Idol)**: 전투 승리 골드 획득량 25% 증가.
- ✴️ **검은 별 (Black Star)**: 엘리트 몬스터 처치 시 유물을 2개 드롭.

### 5. 🔊 Web Audio API 내장 사운드 신시사이저
외부 `.mp3`나 `.wav` 파일 다운로드 없이 브라우저 내장 Web Audio API를 활용한 순수 수학적 파형 합성 사운드:
- 🎴 **카드 드로우음**: 밴드패스 필터를 통과하는 화이트 노이즈 스위프.
- ⚔️ **타격/강타음**: 묵직한 서브 베이스 펀치와 왜곡 트랜지언트.
- 🛡️ **방패 방어음**: 맑고 공명감 있는 금속성 벨 사운드.
- 🧪 **독/디버프음**: 음산한 FM 주파수 모듈레이션 효과.
- 🎺 **승리 팡파르**: C-E-G-C 메이저 아르페지오 및 승리 팡파르.

### 6. 🤖 지능형 자동 진행 (Auto-Pilot AI) & 배속 재생 (1x / 2x / 5x)
- 상단 네비게이션 바의 **`🤖 자동 진행`** 토글 버튼으로 즉시 AI 자동 플레이 활성화.
- **`⚡ 배속 버튼`**을 통해 `1x` (일반 속도), `2x` (2배속), `5x` (5배속 초고속) 실시간 전환 지원.
- **휴리스틱 AI 전략 엔진 (`AutoPilotEngine`)**:
  - **전투 수리 계산**: 적 공격 인텐트, 취약/약화 상태를 정확히 계산하여 잉여 방어 없는 긴급 방어도 충족.
  - **킬각(Lethal) 자동 포착**: 보유한 공격 카드의 데미지 수치 및 대상의 방어도/체력을 정밀 대조하여 즉시 적 격파.
  - **아키타입 시너지 연계**: 파워 카드 선장착(`악마화`, `바리케이드`), 누적 방어도 기반 `몸통 박치기` 및 `참호 구축`, 맹독 중첩 시 `촉매` 폭발.
  - **타겟 집중 사격 (Focus Fire)**: 체력이 가장 낮은 적을 우선 타격하여 받는 피해 최소화.
  - **스마트 노드 탐색**: 체력 비율에 따른 휴식처 모닥불 우선 선택, 골드 보유량에 따른 상점 방문, 덱 완성도에 따른 엘리트 선별 전투.
  - **상점 & 보상 최적화**: 1순위 핵심 파워/유물 구매 및 기본 타격 제거, 3지선다 카드 보상 티어리스트 자동 선별.
- **시뮬레이션 검증 완료**: 1층부터 15층 정상 보스 '공허의 군주(Void Sovereign)'까지 인간 개입 없이 100% 완전 자율 클리어 및 승천 난이도 해금 검증.

### 7. 💾 무손실 자동 저장 & 승천(Ascension 1~5) 메타 진행도
- `localStorage`를 통한 실시간 자동 저장: 전투 중이거나 맵 이동 중 브라우저를 새로고침하거나 창을닫아도 **100% 이전 상태 그대로 이어하기** 지원.
- **승천(Ascension) 난이도 시스템**:
  - **승천 0**: 기본 밸런스 난이도.
  - **승천 1**: 엘리트 몬스터 공격력 +15% 및 정예도 상승.
  - **승천 2**: 일반 몬스터들의 기본 공격력 +10% 상승.
  - **승천 3**: 휴식처 체력 회복량이 30%에서 20%로 감소.
  - **승천 4**: 시작 최대 체력 10 감소 (80 ➔ 70).
  - **승천 5**: 최종 보스의 체력 +25% 증가 및 광폭화 페이즈 발동.
  - *15층 보스를 격파할 때마다 다음 승천 난이도가 영구 해금됩니다.*

## 🚀 실행 방법 (Local Run)

본 프로젝트는 설치나 빌드 과정이 일체 필요하지 않습니다.

```bash
# 저장소 복제
git clone https://github.com/jeiel85/iron-ascension.git

# 폴더 이동
cd iron-ascension

# 브라우저에서 index.html 열기 (Chrome, Edge, Safari, Firefox 등)
# Windows:
start index.html
# Mac:
open index.html
```

## 🛠️ 기술 스택
- **Language**: Vanilla ES6+ JavaScript, HTML5, CSS3
- **Audio Engine**: Web Audio API (OscillatorNode, BiquadFilterNode, AudioBufferSourceNode)
- **Persistence**: Web Storage API (`localStorage`)
- **Graphics & UI**: Pure CSS Responsive Grid/Flexbox, SVG Graph Rendering, Keyframe Shaders
